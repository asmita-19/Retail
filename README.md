# Retail
RetailPulse AI is an interactive Power BI dashboard project featuring 12 pages of retail analytics. It analyzes sales, revenue, profit, product performance, customer behavior, regional trends, and inventory risks using KPIs, charts, slicers, Power Query, and DAX to generate meaningful business insights and support data-driven decisions.
